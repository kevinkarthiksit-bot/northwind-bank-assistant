# Password reset

## Start a reset
Use Forgot password on the Northwind login screen. Northwind sends a one-time code to the registered mobile number or email.

## Code expiry
The reset code expires after 10 minutes. After three failed attempts, the customer must wait 30 minutes before trying again.

## After reset
The customer must sign in with the new password. Chat agents never ask for the full password or the one-time code.
